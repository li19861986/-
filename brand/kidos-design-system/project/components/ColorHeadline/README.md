# ColorHeadline

כותרת שבה כל אות בצבע אחר, במחזור כחול, ורוד, ורוד, כחול, ליים, עם קו מתאר נייבי, כמו המילה "קידוס" בלוגו.

- פעם אחת בעמוד לכל היותר, בכותרת ה־hero. כל שאר הכותרות ב־`ink`.
- טקסט קצר, עד 3 מילים. `aria-label` מקבל את הטקסט המלא כך שקוראי מסך לא מפרקים אותו לאותיות.
- `tones` מאפשר לשנות את המחזור, רק מתוך `blue`, `pink`, `lime`.
