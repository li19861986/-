# PackageCard

אריח חבילה מהמחירון: שם, סלוגן, מחיר, רשימת "כלול", תגיות משתתפים ומשך, הטבה וכפתור.

- הצרכן מספק: `name` (שם החבילה בדיוק כפי שהוא), `tagline`, `price` (מספר, מוצג ₪1,800), `features` (4 עד 7 שורות), `participants`, `duration`, ואופציונלית `perk`, `note`, `action`, `onSelect`.
- `featured` מסמן חבילה אחת בלבד בכל רשת: קו מתאר נייבי, צל ממתק ודגל `sun` "הכי משתלם". הכפתור שלה הוא candy; בשאר הכרטיסים הכפתור כחול.
- ברשת, כל הכרטיסים באותו גובה והכפתור נצמד לתחתית.
- `note` לתנאים ("חבילה זו אינה ניתנת לשדרוג"), `perk` להטבות על רקע `peach`.
