# PriceRow

שורת תוספת במחירון: שם, הערה אופציונלית ומחיר ב־`pink-deep`, עם קו מקווקו מתחת.

- לדוכני מזון, תפאורות, מתנפחים ושונות. חבילות מלאות משתמשות ב־`PackageCard`.
- הצרכן מספק `name`, `price` (מספר או מחרוזת כמו "₪350 לשעה") ואופציונלית `note`.
- שורות בתוך `surface`; מחירים מיושרים בזכות `tabular-nums`.
