# Badge

תגית עובדה קצרה על חבילה או פריט: כמות משתתפים, משך, "כלול".

- `lime`: כמות משתתפים ו"כלול". `sky`: משך. `sun`: "הכי משתלם", פעם אחת בתצוגה. `pink`: "חדש". `neutral`: הגבלות ("חבילה זו אינה ניתנת לשדרוג").
- הצרכן מספק טקסט של 1 עד 4 מילים ואופציונלית `icon`.
- טקסט על `lime` ו־`sun` תמיד נייבי; לא להחליף ללבן.
