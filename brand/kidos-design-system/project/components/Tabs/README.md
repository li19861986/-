# Tabs

פס טאבים בצורת גלולה לקטגוריות המחירון: חבילות הפעלה, דוכני מזון, תפאורות, מתנפחים, שונות.

- הטאב הפעיל ב־`blue` עם טקסט לבן. בגלילה הפס נדבק למעלה עם `shadow-lift`.
- הצרכן מספק `items` (`value`, `label`) ו־`value`/`onChange`, או `defaultValue`.
- תוויות בלי אימוג'י; אם צריך אייקון, לפי כללי האיקונוגרפיה ב־README.
