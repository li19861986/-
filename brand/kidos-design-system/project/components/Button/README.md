# Button

כפתור ממתק: מילוי צבעוני, קו מתאר נייבי `stroke-outline` וצל `shadow-candy` שנעלם בלחיצה.

- `variant="candy"` (ברירת מחדל, `pink`) לפעולה העיקרית, פעם אחת בכל תצוגה: "להזמנת חבילה", "דברו איתנו".
- `variant="blue"` לפעולה משנית ולכפתור של כרטיס חבילה רגיל.
- `variant="quiet"` לקישור טקסט ב־`link`.
- `size="s"` עובר אוטומטית ל־`pink-deep` כדי שהטקסט הלבן הקטן יעמוד ב־4.5:1.
- הצרכן מספק: `children` (פועל בפנייה ברבים, בלי אימוג'י), `onClick`, ואם צריך `disabled`.
- לא לשים שני כפתורי candy זה ליד זה.
