# Sticker

מסגרת מדבקה עגולה: טבעת צבעונית, ואחריה נייבי, לבן ונייבי (`shadow-sticker`), כמו שולי הלוגו.

- ללוגו, לתמונת מפעיל או בובה עגולה, ולמחיר "החל מ־" בולט.
- הצרכן מספק `src` ו־`alt`, או `children` (טקסט קצר ב־`display`), וגודל ב־px.
- `ring`: `lime` ללוגו (כמו הטבעת החיצונית שלו), `pink` למחיר, `blue` לתמונות.
- לא יותר משלוש מדבקות בתצוגה אחת.
